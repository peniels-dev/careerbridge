# CareerBridge – Job and Internship Portal

## Project Description
CareerBridge is a job and internship portal designed to connect job seekers and students with companies offering employment and internship opportunities.

## Project Objectives
- Help users find suitable job and internship opportunities.
- Allow users to create and manage their profiles.
- Allow users to create and manage their CV information.
- Allow users to apply for jobs.
- Allow users to track their applications.
- Allow companies to post and manage job opportunities.
- Provide administrators with tools to manage users and job listings.

## User Types

### Job Seeker
- Register and log in
- Manage profile
- Manage CV
- Browse available jobs
- Filter jobs
- Apply for jobs
- Track applications

### Company
- Create and manage company profile
- Post job opportunities
- Edit job postings
- Close job postings
- Review applicants
- Shortlist or reject applicants

### Administrator
- Manage users
- Manage job postings
- Manage job categories
- Monitor the system through an admin dashboard

## Main Features
- User registration and login
- Profile management
- CV management
- Job browsing and filtering
- Job applications
- Application tracking
- Company profiles
- Job posting and management
- Applicant shortlisting and rejection
- Administrator dashboard
- User and job management

## Technology Stack
- Frontend: React and Material UI
- Backend: Node.js and Express
- Database: Microsoft SQL Server
- API: REST API using JSON
- Version Control: Git and GitHub
